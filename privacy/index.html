Política de Privacidade

METRIK Media Manager · Última atualização: 28 de abril de 2026

1. Quem somos

O METRIK Media Manager é uma ferramenta interna de uso single-user, operada por Rodrigo Rosar (METRIK Instituto), CNPJ disponível mediante solicitação. Contato: rodrigo@rodrigorosar.com.br.

2. Quais dados coletamos

O aplicativo acessa, via APIs oficiais do TikTok, Instagram e Meta, exclusivamente os seguintes dados da conta autorizada pelo próprio criador:

  • Identificadores públicos da conta (open_id, username, avatar)
  • Tokens de autenticação OAuth (access_token e refresh_token)
  • Métricas públicas de posts publicados pela própria ferramenta (visualizações, curtidas, comentários, salvamentos, compartilhamentos)
  • Conteúdo (vídeo MP4 + legenda + hashtags) carregado pelo próprio criador no calendário editorial do Notion

Não acessamos contatos, mensagens, listas de seguidores nem qualquer dado de terceiros. A ferramenta opera apenas sobre a conta única do criador autorizado.

3. Como usamos os dados

Os dados são usados exclusivamente para:

  • Publicar vídeos no TikTok do criador autorizado, a partir do calendário no Notion
  • Atualizar o calendário com o ID e métricas dos posts publicados
  • Renovar tokens de acesso automaticamente (refresh_token) sem intervenção manual

4. Onde os dados ficam armazenados

  • Tokens OAuth são armazenados em GitHub Secrets do repositório privado do criador, criptografados em repouso pela infraestrutura do GitHub.
  • Vídeos são armazenados em bucket privado no Supabase Storage, com acesso controlado por chave de serviço.
  • Metadados (legendas, IDs de post, métricas) são armazenados no calendário Notion privado do criador.

Nenhum dado é compartilhado com terceiros. Não há servidor backend público nem banco de dados com dados de outros usuários.

5. Por quanto tempo guardamos

  • Tokens são guardados enquanto o app permanecer autorizado pelo criador. A revogação encerra imediatamente o acesso.
  • IDs de posts publicados e métricas permanecem no Notion indefinidamente, como histórico editorial do criador.
  • Vídeos no Supabase são removidos manualmente pelo criador conforme política interna.

6. Direitos do criador (você)

Como única pessoa cuja conta é processada por este app, o criador pode a qualquer momento:

  • Revogar a autorização do app diretamente no painel TikTok (Settings > Apps and websites)
  • Solicitar a exclusão de tokens armazenados (basta apagar os GitHub Secrets correspondentes)
  • Apagar todo o histórico no Notion e Supabase a qualquer momento

7. Cookies

As páginas de OAuth deste hub usam apenas sessionStorage do navegador para guardar um estado CSRF temporário durante o fluxo de autorização. Nenhum cookie persistente é colocado, nenhum tracker de terceiros é carregado. Páginas têm noindex,nofollow.

8. Alterações nesta política

Mudanças serão publicadas nesta mesma URL com a data de atualização revisada. Como é uma ferramenta single-user, mudanças materiais são comunicadas diretamente ao criador autorizado.
